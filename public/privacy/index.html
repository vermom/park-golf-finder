내 정보와 저장 목록

내 정보에 입력한 활동 지역, 시·군·구, 소속 클럽, 협회 회원 여부·회원번호와 관심·신청 완료 표시는 사용 중인 브라우저 안에만 저장됩니다. 운영자 서버나 GitHub 저장소로 전송되지 않습니다.

이름, 전화번호, 생년월일, 상세주소는 입력받지 않습니다. 브라우저 저장값은 암호화되지 않으므로 공용 기기에서는 다른 사용자가 회원번호를 포함한 저장 내용을 볼 수 있습니다. 공용 기기에서는 내 정보를 저장하지 마세요.

현재 위치

거리 보기 버튼을 누른 경우에만 브라우저가 위치 권한을 요청합니다. 위치는 경기장까지의 경로 계산에 일시적으로 사용되며 이 사이트 운영자가 따로 저장하지 않습니다. 경로 계산 서비스에는 출발지와 도착지 좌표가 전달될 수 있습니다.

외부 접수처

공식 공고, 지도, 접수 페이지는 외부 사이트입니다. 해당 사이트에서 입력하는 개인정보는 각 사이트의 처리방침이 적용됩니다.

광고와 로그인

현재 홈페이지에는 광고, 회원가입, 로그인, 방문자 추적 도구가 연결되어 있지 않습니다. 추후 광고나 계정 기능을 추가할 경우 실제 적용 전에 이 안내를 갱신합니다.

내 정보 삭제

홈페이지의 내 정보 창에서 내 정보 삭제를 누를 수 있습니다. 관심·신청 완료 목록까지 모두 지우려면 브라우저 설정에서 이 사이트의 저장 데이터를 삭제하세요.
