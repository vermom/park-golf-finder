# 파크골프 대회 찾기

전국의 파크골프 이용자가 대회를 놓치지 않도록 만든 모바일 우선 정적 홈페이지입니다. 별도 회원가입 없이 내 정보, 관심 대회와 신청 완료 상태를 현재 브라우저에만 저장합니다.

## 무엇이 들어 있나요

- 대회명·지역·개최일·접수 상태·참가 자격·개인전/단체전 검색과 필터
- 개최일 최신순·접수 마감일순 정렬, 사용자가 등록한 활동 지역 우선 보기
- 관심 대회와 신청 완료 표시(`localStorage` 사용)
- 활동 지역·시군구·소속 클럽·협회 회원 여부·회원번호를 기기에만 저장하는 `내 정보`
- 신청한 대회의 전체 기간·예선·결선 날짜 충돌 경고
- 공식 공고·접수 페이지·첨부 요강 링크
- 세부 날짜를 아직 자동 해석하지 못한 공식 게시판 공고도 별도 목록으로 노출
- 새 공식 공고를 기존 대회와 이름으로 자동 매칭하고 여러 공식 출처를 한 카드에 연결
- 공고 본문과 PDF에서 날짜·장소·자격·인원·참가비를 읽어 대회 카드로 자동 승격
- 마지막 수집 시각, 출처별 성공·실패·수동 확인 상태
- 모바일 큰 글씨·큰 버튼, 로딩·빈 결과·오류 안내
- 한 줄에 한 장씩 이어지는 대회 카드와 현재 위치 기준 자동차 거리·예상 시간
- Android·iPhone 홈 화면에 무료로 설치하는 PWA와 기본 오프라인 화면
- GitHub Actions 자동수집·검증·무료 GitHub Pages 배포

## 휴대폰에 앱처럼 설치하기

홈페이지 위쪽의 **앱 설치** 버튼을 누릅니다.

- Android Chrome: 표시되는 **설치**를 누르거나 점 3개 메뉴에서 **앱 설치/홈 화면에 추가**를 선택합니다.
- iPhone Safari: 아래쪽 **공유** 버튼 → **홈 화면에 추가** → **추가**를 누릅니다.
- Samsung Internet: 홈페이지의 **홈 화면에 설치 → Chrome에서 설치 계속 → 휴대폰에 앱 설치**를 차례로 누릅니다. Chrome은 설치할 때 한 번만 열리며, 설치 후에는 휴대폰 홈 화면의 **파크골프 대회** 아이콘으로 주소창 없이 실행됩니다. 경고가 이미 보인다면 **무시하고 설치하기**를 누르지 말고 **확인**으로 닫습니다.

앱스토어 등록비는 들지 않으며, 홈페이지가 갱신되면 설치한 웹앱에서도 새 내용을 불러옵니다. 처음 한 번 온라인에서 연 뒤에는 연결이 잠시 끊겨도 이전에 본 화면과 대회 자료를 다시 볼 수 있습니다.

처음 방문할 때는 설치 안내를 자동으로 띄우지 않습니다. 사용자가 홈페이지 위쪽의 **홈 화면에 설치**를 눌렀을 때만 안내를 표시합니다. Android Chrome에서는 **휴대폰에 앱 설치**를 누른 뒤 운영체제 확인창에서 **설치**만 누르면 됩니다. Samsung Internet에서는 Play Protect 경고를 유발하는 브라우저 설치창을 호출하지 않고, 사용자가 설치를 선택한 경우에만 Chrome의 설치 전용 안내로 이어집니다. 아이폰은 운영체제 정책상 자동 설치가 허용되지 않으므로 **공유 → 홈 화면에 추가 → 추가** 순서를 큰 글씨로 안내합니다. 카카오톡 등 앱 안의 브라우저에서는 설치 메뉴가 없을 수 있으므로 먼저 **다른 브라우저로 열기**를 사용합니다.

Chrome에서 설치 버튼이 나오지 않으면 이미 같은 앱이 설치되었을 수 있습니다. 삼성폰 홈 화면에서 위로 밀어 앱스 화면을 연 뒤 **파크골프 대회** 아이콘을 길게 누르고 **홈 화면에 추가**를 선택합니다. 앱스 화면에도 없다면 **설정 → 애플리케이션 → 파크골프 대회 → 삭제** 후 다시 설치합니다. 홈페이지는 이 상황을 감지하면 같은 안내를 큰 글씨로 표시합니다.

## 내 정보 사용하기

1. 홈페이지 위쪽의 **내 정보 등록**을 누릅니다.
2. 주로 활동하는 시·도를 선택하고 필요한 경우 시·군·구, 소속 클럽, 협회 회원 여부와 회원번호를 입력합니다.
3. 저장하면 등록한 시·도의 대회가 먼저 표시되고 **내 지역만** 필터를 사용할 수 있습니다.
4. 대회 카드의 **신청할 때 내 정보 보기**를 열어 입력 내용을 확인합니다.

내 정보는 실제 대회 접수처로 자동 제출되지 않습니다. 이름, 전화번호, 생년월일, 상세주소는 입력받지 않으며 회원번호를 포함한 저장값은 사용 중인 브라우저 밖으로 전송되지 않습니다. 브라우저 저장값은 암호화되지 않으므로 같은 기기와 브라우저를 함께 사용하는 사람은 볼 수 있습니다. 공용 기기에서는 사용하지 않습니다.

## 현재 데이터 출처

`sources.yml`에는 2026-09-05 실제 웹 검색과 접속 시험으로 확인한 중앙 협회, 17개 시·도 범위의 협회·지자체·체육회·시설공단 대표 출처가 있습니다.

- **완전한 대회 카드 자동수집:** 대한파크골프협회 공개 대회 목록·상세 JSON API와 부산시 생활체육포털 공개 JSON을 연결했습니다. 2026-09-05 로컬 시험에서 협회 30건과 부산시 18건을 읽었습니다.
- **공식 공고 자동 발견·매칭:** 대한파크골프연맹, 강원특별자치도·전라남도·제주특별자치도 파크골프협회, 경기도장애인골프협회 게시판을 연결했습니다. 이름이 같은 중앙·지역 공고는 한 대회 카드에 자동 연결합니다.
- **본문·첨부 자동해석:** 강원 협회의 HWP 변환 본문과 제주 협회의 PDF 요강에서 개최 기간, 예선·결선, 경기장, 참가 자격, 인원, 참가비, 주최·주관을 읽습니다. 날짜와 대회명이 확인되면 일반 대회 카드로 자동 승격합니다.
- **판단 보류:** 일정표처럼 여러 대회가 섞였거나 이미지에서 날짜를 확실히 읽지 못한 경우에는 억지로 카드화하지 않고 홈페이지의 **다른 공식기관 새 공고**에 `세부 내용 확인 필요`로 남깁니다.
- **수동등록 예시:** 대한파크골프연맹의 「제1회 우리육우 전국파크골프대회」 공식 이미지 공고를 사람이 확인해 입력했습니다.
- **수동 확인:** 이미지/HWP 중심, 로그인 흐름, 통합게시판 등 안정적인 공개 피드를 확인하지 못한 지역 출처는 억지로 우회하지 않고 `manual_required`로 표시합니다.

블로그·카페는 발견용 참고자료일 뿐 데이터의 공식 링크로 사용하지 않습니다. 출처 링크를 추측해서 만들지 않습니다.

전국의 공고는 시·군·구 홈페이지, 협회, 체육회, 시설공단에 흩어져 있고 일부는 검색·로그인·이미지 공고만 제공하므로 인터넷에 게시된 모든 공고를 100% 자동수집한다고 보장할 수는 없습니다. 대신 17개 시·도의 대표 공식 출처를 빠짐없이 상태 목록에 두고, 자동으로 읽히는 곳은 공고 단계에서 먼저 노출하며, 막힌 곳은 **수동 확인 필요** 또는 **수집 실패**로 공개합니다. 이 상태 표시는 누락을 성공으로 오인하지 않게 하기 위한 장치입니다.

## 내 컴퓨터에서 실행하기

Node.js 24와 Python 3.12가 필요합니다.

```bash
npm install
python -m pip install -r requirements.txt
python scripts/collect.py
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 테스트하기

```bash
npm test
npm run lint
python -m pytest -q
python scripts/validate_data.py
npm run build
```

실제 링크까지 확인하려면 아래 명령을 추가로 실행합니다. 외부 사이트가 점검 중이거나 자동 접속을 제한하면 링크 검사만 실패할 수 있습니다.

```bash
python scripts/validate_data.py --check-links
```

## Excel에서 대회를 수동으로 추가하기

1. `data/manual_events.csv`를 Excel로 엽니다. 이 파일은 한글이 깨지지 않는 UTF-8 BOM CSV입니다.
2. 마지막 줄 아래에 한 줄을 추가합니다.
3. `id`는 겹치지 않게 `manual-지역-대회명-연도`처럼 씁니다.
4. 날짜는 `2026-10-12`, 시각은 `2026-09-04T17:00:00+09:00` 형식으로 씁니다.
5. 여러 값은 `|`로 나눕니다. 예: `개인전|단체전`.
6. 공식 공고 주소가 없으면 임의 주소를 만들지 말고, 공식 공고를 찾은 뒤 입력합니다.
7. 저장할 때 파일 형식을 **CSV UTF-8(쉼표로 분리)** 로 선택합니다.
8. `python scripts/collect.py`를 실행해 홈페이지용 JSON에 합칩니다.

열별 자세한 설명은 `data/README.md`에 있고, 첫 행에는 실제 공식 공고를 바탕으로 한 입력 예시가 있습니다.

## 새로운 자동수집처 추가하기

1. `sources.yml`에 공식 출처를 추가합니다. 공개 페이지가 안정적으로 읽힐 때만 `mode: auto`로 둡니다.
2. 세부 항목까지 구조화된 출처는 `collectors/` 아래에 사이트별 수집기 파일을 만듭니다. 한 사이트의 HTML 구조가 바뀌어도 다른 출처가 영향을 받지 않도록 분리합니다.
3. 첨부 요강 중심의 일반 게시판은 `collector: official_notice`, `list_urls`, 필요하면 `detail_link_regex`를 지정해 공식 공고 후보부터 자동 발견할 수 있습니다.
4. 로그인·캡차·본인인증·로봇 차단은 우회하지 않습니다. 해당 출처는 `mode: manual_required`로 둡니다.
5. PDF/HWP/HWPX 내용을 읽지 못해도 `attachments`에 첨부와 원문 주소를 남깁니다.
6. 수집 결과는 `schema/events.schema.json`을 통과해야 합니다. 완전한 대회는 `events`, 세부 해석 전 공식 공고는 `notices` 배열에 저장됩니다.

## 자동 갱신 방식

`.github/workflows/update-data.yml`이 한국시간 매일 오전 6시와 오후 6시에 실행됩니다. **Actions → 대회 데이터 자동수집 → Run workflow** 버튼으로 수동 실행할 수도 있습니다.

- 수집 전 기존 `events.json`을 읽습니다.
- 출처 하나가 실패하면 그 출처의 기존 정상 대회와 공식 공고 후보를 보존합니다.
- 대회명·지역·시작일을 정규화해 중복을 합칩니다.
- 새 공고의 대회명에서 `요강·알림·공지` 같은 문구를 제거한 뒤 기존 대회와 비교합니다. 유사 후보가 둘 이상이면 자동으로 고르지 않고 확인 대상으로 남깁니다.
- 공고 본문과 PDF의 `기간·장소·참가자격·참가인원·참가비` 항목을 해석하고, 축약된 날짜 범위도 한국시간 날짜로 변환합니다.
- 전체 결과를 임시 파일로 만든 뒤 스키마와 날짜를 검증하고 정상일 때만 교체합니다.
- 오류 원인과 출처별 상태는 Actions 로그와 홈페이지 하단에 남습니다.
- 실제 Git 변경이 있을 때만 커밋합니다.
- 새 경기장 주소는 자동수집 때 공개 주소 지오코더로 좌표를 확인하고 `data/geocode_cache.json`에 저장합니다.

GitHub의 예약 작업은 정확한 시각보다 조금 늦게 시작될 수 있습니다. 공개 저장소가 60일 동안 활동이 없으면 예약 workflow가 자동 비활성화될 수 있습니다. 이 경우 **Actions → 대회 데이터 자동수집 → Enable workflow**를 누르고 한 번 수동 실행하세요. 사이트 구조가 바뀌어 실패하면 Actions의 빨간 실행 기록을 열고 **공식 출처 수집 및 기존 데이터 병합** 단계를 확인합니다.

## GitHub Pages에 무료 배포하기

처음 한 번만 아래 순서대로 합니다.

1. GitHub 오른쪽 위 **+** → **New repository**를 누릅니다.
2. Repository name에 정확히 `park-golf-finder`를 입력합니다.
3. 무료 Pages를 위해 **Public**을 선택합니다.
4. **Add a README file**은 체크하지 않고 **Create repository**를 누릅니다.
5. 이 폴더를 새 저장소의 `main` 브랜치로 push합니다.
6. 저장소에서 **Settings** → 왼쪽 **Pages** → **Build and deployment**의 **Source**를 **GitHub Actions**로 선택합니다.
7. **Actions** 탭 → **GitHub Pages 배포** → **Run workflow**를 누릅니다.
8. 초록색 완료 뒤 주소는 `https://내-GitHub-아이디.github.io/park-golf-finder/`입니다.

배포 workflow는 저장소 이름을 자동으로 읽어 CSS, JavaScript, JSON 경로 앞에 `/park-golf-finder`를 붙입니다. 따라서 GitHub Pages 하위 경로에서도 파일이 깨지지 않습니다.

## 개인정보와 주의사항

- 이 저장소와 JSON에는 개인 이름·전화번호·회원번호를 넣지 않습니다.
- 내 정보의 회원번호와 관심/신청 상태는 사용자 기기의 `localStorage`에만 저장되며 서버로 전송되지 않습니다. 브라우저 저장값은 암호화되지 않으므로 공용 기기에서는 사용하지 않습니다.
- 현재 위치는 사용자가 **내 위치로 거리 보기**를 누르고 브라우저 권한을 허용한 경우에만 사용하며 저장하지 않습니다.
- 자동차 거리·시간은 OpenStreetMap 도로망 기반 BRouter의 예상값입니다. 교통 정체는 반영하지 않으며, 경기장 주소가 읍·면·동 단위로만 확인되면 실제 입구와 다소 차이 날 수 있으므로 **길찾기**에서 최종 확인하세요.
- 공개 서비스로 사용할 수 있도록 일반 대회 페이지의 검색엔진 색인을 허용합니다. `localStorage`에 있는 내 정보는 정적 HTML이나 검색엔진용 파일에 포함되지 않습니다.

- 접수 전에는 반드시 카드의 공식 공고에서 자격·인원·참가비·시간을 다시 확인하세요.
